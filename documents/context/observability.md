# Observability Context

## Purpose
> 서버 모니터링 서비스로, 실시간 데이터 전송 API를 제공합니다.

## Responsibilities
* 서버 모니터링
* 모니터링 데이터 실시간 전송 API (SSE)

## Owns
> 이 Context가 소유하는 데이터/엔티티에 대해서 작성합니다.

## Dependencies
> 이 Context가 의존하는 Context 또는 외부 시스템에 대해 작성합니다.

## Out of Scope
> 필요할 경우 이 Context가 책임지지 않는 기능을 작성합니다
