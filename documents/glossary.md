# 용어 사전

| 영문명         | 한글명           | 설명                                                            |
|-------------|---------------|---------------------------------------------------------------|
| application | 원서            |                                                               | 
| analytics   | 통계            |                                                               |
| schedule    | 일정            | 원서 지원 일정, 합격 발표 일정을 다룹니다.                                     |
| qna         | 자주 묻는 질문, QnA | 자주 묻는 질문이지만 FAQ가 아닙니다.                                        |
| notice | 공지사항          | notification 서비스와 헷갈리는 것을 방지하기 위해 notice를 사용합니다.              | 
| notification | 공지 게시글        | 공지사항이 아니라 공지사항, qna, 전형요강 전체를 다루는 서비스입니다.                     |
| documents | 개발 문서         | 프로젝트 개발, 설계에 대한 문서를 의미합니다.                                    |
| document | 파일 | 단순 문서를 의미하는게 아닌 이미지, pdf, hwp 등 다른 서비스에서 필요한 파일을 제공하는 서비스입니다. |
